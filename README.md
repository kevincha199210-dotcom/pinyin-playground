# 拼音小乐园

一个面向 5 岁儿童的汉语拼音启蒙前端小程序。无需登录、无需后端、无需安装依赖，学习进度只保存在浏览器本机。

## 功能

- 拼音卡片：23 个声母、6 个单韵母、8 个复韵母、8 个鼻韵母
- 四声小火车：a、o、e、i、u、ü 的四声互动练习
- 书写笔顺：12 个基础拼音字母的分步动画、触控描写画板和完成奖励
- 看图闯关：每轮随机 8 题，支持错题重试和星星奖励
- 语音播放：预生成的普通话 AI 声音 MP3，手机浏览器无需内置语音引擎
- 儿童友好：大按钮、低文字密度、无广告、无个人信息收集
- 离线使用：通过 Service Worker 缓存页面；已播放过的音频也会缓存
- 移动端适配：手机、平板和桌面浏览器均可使用

## 运行

直接双击 `index.html` 可以使用大部分功能。为启用离线缓存，建议在本目录运行：

```powershell
python -m http.server 4173
```

然后打开：<http://127.0.0.1:4173>

公开访问：<https://kevincha199210-dotcom.github.io/pinyin-playground/>

`audio/` 中的音频是预先生成的静态文件。第一次播放需要网络，之后会缓存到浏览器；访客播放时不会调用语音合成服务。

## 数据说明

星星数、已学会的卡片和每日目标存储在浏览器的 `localStorage` 中，不会上传到服务器。家长可以在右上角设置中清空记录。
